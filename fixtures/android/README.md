# Android build probes

Original Apache-2.0 fixtures. Each F1–F4 directory is an independent Gradle build;
keep the parent directory because settings and SDK configuration are shared.
These probes do not install SDK packages, devices, or Android Studio components.

| Fixture | Coverage |
| --- | --- |
| `f1-java-xml` | One Java/XML application, Android `R` |
| `f2-compose` | One Kotlin/Compose application, no Preview |
| `f3-flavors` | Application + library; public/internal resource overrides and application IDs; debug trace constant |
| `f4-generated` | Kotlin calls Java, Java calls Kotlin; `R`, `BuildConfig`, original kapt processor |

`matrix.json` pins conservative AGP 8.13.2 / Gradle 8.14.6 / Kotlin 2.3.21 and
current AGP 9.5.1 / Gradle 9.6.0 / Kotlin 2.4.21. Compose compiler matches Kotlin.
AGP 9 uses built-in Kotlin and `com.android.legacy-kapt`; AGP 8 uses Kotlin Android
and kapt. Both target JDK 21, compile SDK 36, build-tools 36.0.0, min SDK 23.
Compose foundation 1.7.8 intentionally remains identical across the matrix.
Wrappers are generated by Gradle and verify official distribution SHA-256.

## Native builds (PowerShell)

Set `JAVA_HOME` to your own JDK 21 and `ANDROID_HOME` to an existing SDK containing
platform 36 and build-tools 36.0.0. Do not commit `local.properties`.

```powershell
$env:GRADLE_USER_HOME = "$env:USERPROFILE\oas-gh"
$env:PYTHONIOENCODING = 'utf-8'
python fixtures\android\build-fixtures.py --toolchain conservative --evidence "$env:TEMP\oas-conservative"
python fixtures\android\build-fixtures.py --toolchain current --evidence "$env:TEMP\oas-current"
```

This invokes native `gradlew.bat`, sequentially, with `--no-daemon`. The equivalent
single-project command from the checkout root is:

```powershell
.\fixtures\android\toolchains\conservative\gradlew.bat -p fixtures\android\f1-java-xml -Ptoolchain=conservative :app:assembleDebug --no-daemon --console=plain
```

For current, change **both** wrapper directory and `-Ptoolchain=current`. F3 tasks
are `:app:assemblePublicDemoDebug` and `:app:assembleInternalDemoDebug`; its library
correctly selects `debug` rather than inventing a same-named library flavor.
F4 generates `app\build\generated\source\kapt\debug\...\GeneratedGreeting.java`.
The processor reports write failures as compiler errors, not silent omissions.

`--unicode-root <new-directory>` copies only fixture inputs and builds all four
from that directory; caller owns cleanup. Logs include command, exit code and
elapsed time; downloads make cold/warm times incomparable.

## Version provenance

Queried 2026-11-11; see the G1 validation report for actual results and limitations.

- [Google Maven AGP metadata](https://dl.google.com/dl/android/maven2/com/android/tools/build/gradle/maven-metadata.xml)
- [AGP 8.13 compatibility and 8.13.2](https://developer.android.com/build/releases/agp-8-13-0-release-notes)
- [AGP 9.5 compatibility and 9.5.1](https://developer.android.com/build/releases/agp-9-5-0-release-notes)
- [Gradle releases](https://gradle.org/releases/) — 8.14.6 is the last 8.x patch; 9.6.0 is AGP 9.5's documented minimum/default, not the latest independent Gradle release.
- [Kotlin compatibility](https://kotlinlang.org/docs/gradle-configure-project.html) — 9.5.1 exceeds KGP 2.4.21's fully tested AGP range (9.3.1); integration must prove this combination.
- [Built-in Kotlin and legacy kapt](https://developer.android.com/build/migrate-to-built-in-kotlin)
- [Compose compiler version matching](https://developer.android.com/develop/ui/compose/setup-compose-dependencies-and-compiler)
- [KSP releases](https://github.com/google/ksp/releases) — inspected, not used; latest 2.3.13 documents a concurrent-execution regression.
